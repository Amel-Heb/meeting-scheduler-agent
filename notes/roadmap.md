 # Meeting Scheduler Agent Roadmap

 ## Sprint 1 — Foundations ✅

 Goal:
 Understand the core components of an AI agent.

 Features:
 - Python environment
 - Virtual environment
 - OpenAI connection
 - System prompt
 - Calendar memory
 - Availability tool
 - Meeting model

 Learnings:
 - Difference between chatbot and agent
 - Role of tools
 - Role of environment
 - Role of memory

 ---

 ## Sprint 2 — Tool Orchestration ⏳

 Goal:
 Allow the agent to combine reasoning and tools.

 Features:
 - Check availability
 - Create meeting draft
 - Decision flow

 Expected learning:
 - How an agent decides to act

 ---

 ## Sprint 3 — Human Validation

 Goal:
 Add confirmation before creating a meeting.

 Features:
 - User confirmation
 - Approval flow

 Expected learning:
 - Human-in-the-loop design

 ---

 ## Sprint 4 — Real Calendar Integration

 Goal:
 Connect the agent to a real calendar.

 Features:
 - Google Calendar API
 - Real events

 Expected learning:
 - Agent interacting with real environments

 ---

 ## Sprint 5 — User Interface

 Goal:
 Design an experience around the agent.

 Features:
 - Chat interface
 - User feedback
 - Error handling

 Expected learning:
 - AI UX Design
