# Sprint 2 — Planning

## Goal

Transform the Meeting Scheduler from a collection of tools into an orchestrated AI agent.

---

## User Story

As a user, I want to describe my scheduling request in natural language so that the agent automatically selects the appropriate tool.

---

## Problem

The current application requires directly calling Python functions.

A real AI agent should understand the user's intent before deciding which action to execute.

---

## Acceptance Criteria

- Understand the user's request
- Detect the intent
- Select the appropriate tool
- Execute the tool
- Return the result

---

## Deliverables

- SchedulerAgent
- Tool routing
- Updated architecture
- Updated README
- Sprint Review
